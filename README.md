# homebrew-tap

Homebrew tap for [resonate](https://github.com/jecklgamis/resonate) and [microtunnel](https://github.com/jecklgamis/microtunnel).

```sh
brew install jecklgamis/tap/resonate
brew install jecklgamis/tap/microtunnel
```

`Formula/resonate.rb` is generated by `scripts/gen-formula.sh` from a release's
`SHA256SUMS.txt`; resonate's release workflow updates it on every tag.

`Formula/microtunnel.rb` builds from source and is pinned to a release tarball. For a new
microtunnel release, update its `url` and `sha256` (`curl -sL <url> | shasum -a 256`).
